# Claude Agent Notes

This repository is a local-first D&D 5e spellbook and character tracker built with Next.js 16 and App Router.

- Follow the instructions in the repo-level [AGENTS.md](../AGENTS.md).
- Keep all app data browser-local unless the user explicitly asks for a backend.
- Preserve the existing spellbook theme system and IndexedDB storage patterns.
- Prefer minimal, rule-aware changes over broad refactors.
- Verify with the project’s lint/build commands before finalizing changes.
